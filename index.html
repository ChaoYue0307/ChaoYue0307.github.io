Notes

Evaluation before automation. Start with baselines, error analysis, and careful task design.

Reproducibility is a feature. Configs, seeds, data versions, and notes deserve first-class treatment.

Small tools, sharp edges. Utilities should do one thing clearly and compose well.

Interfaces are part of the system. CLIs, logs, docs, and dashboards shape reasoning.

Write to think. Writing turns vague ideas into objects that can be tested and edited.

Make the work useful. A good project helps someone else move faster or see more clearly.
