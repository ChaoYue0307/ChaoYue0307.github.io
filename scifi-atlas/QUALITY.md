# 改进说明与质量检查

本轮在既有科幻创意图谱上改进阅读、检索、收藏、独立页面与维护流程。原始目录及 Excel 保持同一版本：240 条代表性创意、20 个主题、14 种主要媒介。这里记录工程与产品质量；来源支持标签仍须按每条资料的实际范围理解。

## 已处理的问题

| 方面 | 发现的问题 | 改进 |
| --- | --- | --- |
| 阅读与手机排版 | 目录正文、作品信息偏小，部分触控区域不足 | 增大正文字号，主要控件至少 44px；768px 以下改为单列目录，手机筛选保留可见标签 |
| 检索 | 编号混合搜索可能命中其他条目的引用，AI 误中 D-Mail 等单词片段 | 编号始终精确约束当前记录，短英文词按词边界匹配，多词继续 AND 查询 |
| 筛选 | 静态总数不能说明组合条件下的可选范围 | 候选数保留其他已选条件，零结果选项保留但禁用，已选条件仍可移除 |
| 导航与键盘 | 重建列表后焦点容易跳走，模态框末端可进入浏览器界面 | 保留邻近焦点、返回时恢复阅读位置；详情初始聚焦标题，Tab/Shift+Tab 在可用控件间循环 |
| 可访问名称 | 部分 aria-label 未完整包含可见文字 | 对齐品牌、收藏、复制按钮和来源标题及域名，保留新窗口说明 |
| 收藏 | 只有导出，存储失败时连续写入可能丢失会话变更 | 支持本地导入、有效编号合并、重复和未知编号报告、撤销本次新增；失败时保留会话集合 |
| 阅读入口与索引 | 详情只依赖 hash 路由和全量数据加载 | 新增 240 个实体 HTML 详情、完整静态目录、canonical、JSON-LD 和 sitemap；旧链接继续可用 |
| 资源与安全 | 页面需要明确的资源、转义和失败边界 | 同源原生模块、无第三方运行时；来源只接受 HTTP(S)，采用早置 CSP；导入文字与链接不进入页面 |
| 维护 | 容易让数据、预渲染和交互产生偏差 | 提供确定性生成器、只读过期检查、锁定浏览器验证依赖与 scoped CI |

## 验证方式

`npm test` 使用 Node 内置测试器，覆盖真实目录完整性、查询、统计、关联、导入安全、收藏失败恢复，以及静态页生成、安全转义和确定性。`npm run check:build` 检查全部生成页与首页预览是否和当前输入一致，不修改文件。

`npm run test:browser` 在 Chromium 的 1440、1024、768、390、320px 视口和 WebKit 的 390px 视口检查页面。流程包括搜索、组合筛选、分页与浏览器历史、模态框键盘循环、跨标签收藏、导入/撤销、实际文件下载，以及关闭 JavaScript 后的目录和详情。对必要页面运行 axe 的 WCAG A/AA 自动规则，保存报告和截图。

普通浏览器检查执行公开页面真实 CSP。Axe 仅在单独的测试上下文注入本地审计引擎，不修改生产策略。截图使用页面自身的减少动画设置，不通过测试样式绕过 CSP。截图复核采用 Chromium；当前 Playwright 的 WebKit 截图会自动注入内联样式，因此该引擎保留功能、布局、尺寸及 CSP 检查，省略截图调用，报告中单独注明原因。

当前运行记录可在 [Sci-Fi Atlas quality checks](https://github.com/ChaoYue0307/ChaoYue0307.github.io/actions/workflows/scifi-atlas.yml) 查看。工作流仅有仓库内容读取权限；Actions 固定到完整 commit SHA，测试依赖固定版本并提供 package-lock.json。验证报告与截图作为 Actions artifact 保留 7 天。

## 视觉复核与边界

实际截图保留了原有米白底、深蓝正文、少量朱红、中文衬线标题、细分隔线、轨道主题导航、四项统计和开放式目录行。桌面继续使用左侧主题索引；平板和手机转为单列、可见标签及全宽选择器。手机的额外垂直空间用于保持文字和控件易读，长详情标题采用均衡换行。

这些检查不等于全设备或完整 WCAG 合规认证；真实辅助技术、老旧浏览器、系统字体与用户个性化设置仍可能产生差异。Meta CSP 也不提供只能由服务器响应头实现的功能。站点没有服务工作线程，不承诺离线应用行为。自动验证不替代对原作、首创或现实科学可行性的独立核对。

后续编辑请优先保持稳定编号、来源与证据限制，并在改动数据后重新生成独立页。站点收录范围是可继续扩展的代表性目录。
